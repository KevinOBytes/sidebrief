Quick Start Guide

Get up and running with Sidebrief on your Mac in under 2 minutes:

# 1. Download and open Sidebrief.dmg # 2. Drag Sidebrief.app to /Applications # 3. Launch Sidebrief and grant ScreenCaptureKit + Mic permissions # 4. Press ⌃⌥Space (Control + Option + Space) to summon copilot

Sidebrief sits in your menu bar. Choose between free on-device Apple Speech STT or fast Groq Whisper in Settings → AI Providers.

Audio Pipeline Specifications

Sidebrief avoids virtual audio cable drivers by utilizing modern ScreenCaptureKit loopback:

Audio Sources: • Local Mic: AVFoundation AVAudioEngine (16-bit LPCM, 48kHz mono) • System Audio: ScreenCaptureKit SCStream (16-bit LPCM, 48kHz stereo) Processing: • Bounded circular lock-free queue (sub-15ms handoff) • Active Channel VAD Router (350ms hangover, automatic turn commit) • STT: Apple Neural Engine (On-Device) or Groq Whisper Large v3 (~150ms)

System audio and microphone streams are tracked separately with individual timestamps and stream epochs.

Zero-Plaintext Security Invariants

Every spoken word and meeting artifact is treated as confidential:

Key Management: • Every meeting generates a unique 256-bit AES-GCM symmetric key • Keys are committed strictly to macOS Keychain (kSecClassGenericPassword) • Audio chunks are encrypted in-memory before disk commit • Local SQLite database is primary source of truth; zero cloud raw blobs

Offline guarantee: Network unreachability or provider latency never interrupts ongoing local audio recording.

Build from Source

Sidebrief is built with Swift Package Manager and standard Xcode tools:

# Clone the repository git clone https://github.com/KevinOBytes/sidebrief.git cd sidebrief # Run test suite (43 unit tests) swift test # Build release bundle & DMG installer ./scripts/build_dmg.sh

The resulting app bundle will be installed to /Applications/Sidebrief.app with persistent code signing for TCC permissions.
