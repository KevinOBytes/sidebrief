Audio Pipeline Specifications

Sidebrief avoids virtual audio cable drivers by utilizing modern ScreenCaptureKit loopback:

Audio Sources: • Local Mic: AVFoundation AVAudioEngine (16-bit LPCM, 48kHz, mono) • System Audio: ScreenCaptureKit SCStream (16-bit LPCM, 48kHz, stereo) Processing: • Bounded circular lock-free queue (sub-15ms handoff) • Streaming STT: ElevenLabs Scribe v2 with VAD chunk deduplication

System audio and microphone streams are tracked separately with individual timestamps and stream epochs.

Zero-Plaintext Security Invariants

We treat every spoken word and meeting artifact as confidential:

Key Management: • Every meeting generates a unique 256-bit AES-GCM symmetric key • Keys are committed strictly to macOS Keychain (kSecClassGenericPassword) • Audio chunks are encrypted in-memory before disk commit • Cloud sync to Neon PostgreSQL uses Row-Level Security (RLS) and pgvector

Offline guarantee: Network unreachability or cloud latency never interrupts ongoing local audio recording.
